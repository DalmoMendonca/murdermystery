# Character art

Thirty fictional identities, each generated separately in three styles using the built-in image_gen tool. These depict characters rather than actual guests. Facial features, hair, costume palette and signature accessory carry across each trio; the cast varies in silhouette, expression, complexion, hair, eyewear and props.

| Style | Placement |
| --- | --- |
| Van Gogh inspired post-impressionist portrait | Ornate one-page public poster and its 144-dpi JPEG export |
| Picasso inspired cubist portrait | Safe ornate cover of the twelve-page private packet |
| Cute chibi manga avatar | Both faces of a large tent card, one Letter sheet per guest |

`source/art_direction.json` preserves every exact prompt, identity specification and SHA-256. `assets/portraits/<character>/` contains full-resolution portrait assets, with prompts embedded as provenance. Native PNG originals remain at the image tool's local generated-image location; the source portraits preserve the full pixel dimensions at high quality. Builds consume committed assets without generating new images.

The complete kit includes all 90 print-sized portraits in `OPEN_FREELY/Portraits`. These carry harmless origin metadata. Full prompts live in the organizer's source archive because their negative constraints refer to plot objects. Portraits themselves contain no animal assignment or branch-dependent evidence. A character uses the same image regardless of guilt. Both branches use the same portraits. Transparent cutout derivatives are lossless WebP source assets; original opaque images remain editable precursors. Public chibi exports preserve alpha transparency.

Public posters retain a concise biography, immediate relationship context, full-width ACTING TIPS and optional COSTUME SUGGESTIONS. The ornate gilt aperture intentionally crops the poster and cover print compositions without stretching; full-resolution, full-composition masters remain in the source archive. Other image placements retain aspect-fit. Poster body text measures 17 or 16 pt. Private narratives remain at least 14 pt, with ordinary speaking text 16 pt and measured Opportunity boxes sometimes 15 pt. Tent names use 31/38 pt and roles 16 pt. Public posters remain one Letter page without page numbers or ages; the private book is numbered and round-marked.

Day-of introduction page 2 has no artwork or costume guidance. Its relationship names are bold and highlighted yellow, and it includes an individual introduction to read aloud. The cover contains no private grievance, secret, animal or role branch, so packets can be laid face up on assigned seats.

Print derivatives use quality-88 JPEG color; the generated frame retains its native alpha in a lossless PDF soft mask. The original frame PNG remains in `assets/ornaments`, with provenance in `source/ornament_art.json`. This encoding is distinct from preserving full-resolution editable masters. Source evidence art records also include the new clock-comparison photograph, actual-installation photograph and obsolete-display proposal illustration.

Future changes require both an asset review across all three styles and a rendered PDF review. The source and pixel-hash checks detect duplicate images, incorrect asset records, missing image slots and misplaced illustrations in later private rounds. They do not replace visual judgment about distinctness or likeness.
