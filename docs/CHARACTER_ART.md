# Character art

Thirty fictional identities, each generated separately in three styles using the built-in image_gen tool. These depict characters rather than actual guests. Facial features, hair, costume palette and signature accessory carry across each trio; the cast varies in silhouette, expression, complexion, hair, eyewear and props.

| Style | Placement |
| --- | --- |
| Van Gogh inspired post-impressionist portrait | One-page public character sheet and its PNG export |
| Picasso inspired cubist portrait | First page of the four-page private play packet |
| Cute chibi manga avatar | Museum-label place card, four per Letter page |

`source/art_direction.json` preserves every exact prompt, identity specification and SHA-256. `assets/portraits/<character>/` contains full-resolution JPEG assets, with prompts embedded as provenance. Native PNG originals remain at the image tool's local generated-image location; the source JPEGs preserve the full pixel dimensions at high quality. Builds consume committed assets without generating new images.

The complete kit includes all 90 print-sized portraits in `OPEN_FREELY/Portraits`. These carry harmless origin metadata. Full prompts live in the organizer's source archive because their negative constraints refer to plot objects. Portraits themselves contain no animal assignment or branch-dependent evidence. A character uses the same image regardless of guilt. The investigation scripts and selected A/B receipts are unchanged.

Invitations retain the full biography, immediate relationship context, ACTING TIPS and optional COSTUME SUGGESTIONS. Artwork is contained in its frame with no stretching or cropping. Body text stays at 16–18 pt on character sheets and at least 14 pt on private pages and place-card roles. Names remain large. All public introductions remain one Letter page without page numbers or numbered ages.

Future changes require both an asset review across all three styles and a rendered PDF review. The source and pixel-hash checks detect duplicate images, incorrect asset records, missing image slots and misplaced illustrations in later private rounds. They do not replace visual judgment about distinctness or likeness.
