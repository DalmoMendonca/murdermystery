# Playtest and improvements — spoiler-safe

Sixteen independent agents took different guest personas; one also hosted. All 15 innocent agents identified the intended culprit. Each rated difficulty 2/5; the culprit’s self-vote is excluded from accuracy. No premature public confession or branch-label disclosure appeared in the supplied scripted dialogue.

This was a blind asynchronous table read of canonical answers, with persistent text available, rather than a live human party. It did not test distraction, unaided recall, accidental physical page turns, discovery hunting or actual timing. These results cannot predict the real-party solve rate.
