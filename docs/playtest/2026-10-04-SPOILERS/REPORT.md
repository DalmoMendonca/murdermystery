# Agent playtest — detailed feedback (SPOILERS)

Date: October 4, 2026. Baseline: commit c2862d14af8104e596661b3bd993744323f60eb4. This report contains a synthetic culprit assignment, private statements and confessions. A playing host should use the separate spoiler-safe summary.

## What was actually tested

Sixteen independent agents with fresh, empty contexts took sixteen character roles; one also facilitated. Three ran at a time because the environment has four total slots. Each received only its own private pages, simulated memorized animal, attending cast and staged public reports/transcripts. Agents saved Motive hypotheses before Opportunity, Opportunity hypotheses before Method, then locked ballots before any Coming Clean. The adjudicator checked the ballot files remained unchanged throughout reveal.

This was an asynchronous **blind table read**, not a live interactive party. Public dialogue consisted of the kit’s canonical prepared answers in shuffled named question chains. Agents did not choose each other’s live turns or improvise testimony. Text remained available for rereading. Persona differences represent modeled priorities, not human cognition, age or sensory limitations. The inputs omitted pre-party introductions/relationships, discovery hunting and the existing host checklist at first; the host received the real checklist for tally/reveal. Those omissions must not be misreported as absent kit features.

## Results and difficulty

All fifteen innocent agents independently accused the selected culprit. The culprit also voted for themself, explicitly describing that as a deduction-test decision rather than realistic evasion; that vote is excluded from detective accuracy. All sixteen difficulty ratings were 2/5 (1 trivial, 5 too hard); confidence ranged96–99%. Numerical enjoyment ratings were generally 3–4/5. This shows the final three-strand intersection is easy for a language model with persistent transcripts. It is not a prediction of a human party’s solve rate or enjoyment.

No premature public confession, animal identity or IF heading appeared in the scripted utterances. Participants saw both alternatives in their own packets, as the design intends. No neighbour-peeking, mistaken physical page turn, forgotten animal or live accidental disclosure was tested. Zero observed leaks in this format does not establish zero real-world risk.

## Findings used in the improvement round

1. **Evidence bookkeeping exceeded the note space.** Agents repeatedly wanted a comparison grid for names, salon times, key loans and materials. Added two private14pt grids inside every packet, covering all 30 names with attendance ticks. Packets now have 14 pages; ballots13 and Coming Clean 14. No external player catalog was added.
2. **Method could be read incompletely.** Added an explicit entire-box instruction including all three preparation-record lines. Question pages now name the exact answer page. Common Motive explains it is shared by both roles. Handoffs point to the current question pages and notes pages.
3. **The hearings felt procedural.** Kept the user’s grouped questions and distinct answers. Added a bounded three-suspicion discussion after every complete chain, with repeats of the current printed answer permitted. Reports stay visible; host announces full speaker names. Essential facts remain reliable.
4. **Optional roles had generic mingling tasks.** Replaced all 15 optional roles’ generic prompts with two specific named conversations grounded in existing relationships and grievances. Expanded abbreviated core targets, especially Art versus Artie. Removed Barb’s pre-death reference to a murder timeline. Clarified that later printed hearings may reveal ActI secrets.
5. **Barb’s camera paperwork contradicted its clue.** The work order records disconnection; the undocumented fact is Grant’s coercive threat. Innocent closure and background now agree with the actual discovery.
6. **Whole-packet ballot submission exposed private material and deprived guests of their finale.** Ballot remains inside each packet but is left loose during assembly. Guests fold and hand over only that page, retaining questions and Coming Clean. Enlarged host checklist names to14pt; added count-match fields and a tally page.
7. **A unanimous vote shortened the promised three-person finale.** Baseline positive-only rule called just one. Revised rule ranks all attending names including zero, breaks ties alphabetically, and calls exactly three. The host applied this to the actual16 locked votes: Elon, Anya, Artie. Those three agents returned their own statements; Elon confessed, both innocent statements still followed, and no animal fallback was required. Explain zero-vote ties as finale selection, not new accusations.
8. **Award and helper boundaries needed clarity.** Master Sleuth is for innocent guests; culprit knowledge cannot earn that award. Only a non-playing helper may read another guest’s selected private box, keeping the branch private and not voting. Competing neighbours must not be handed someone’s role selection.

## Findings verified and rejected

Several agents claimed Method’s innocent label/header was missing. Direct root inspection and independent review of all 560 distinct rendered pages disproved this. Some agents withdrew the claim after proper image forwarding; the others’ raw feedback is preserved below with this adjudication. No phantom label defect was used to redesign the sheet. The first host input omitted the existing attendance checklist; its initial request for one was a simulation-input omission. The implemented change enlarges and extends that checklist.

We retained unambiguous forensic exclusions and named question groups. Making essential evidence obscure to produce wrong guesses would reduce fairness and accessibility. The improvement round addresses memory support, reading/privacy, character interaction and finale structure; it does not claim to have made the deduction harder.

## Coverage and remaining limits

Only one synthetic culprit and one 16-character cast were used in agent table reads. Automatic checks separately cover120 culprit/attendance cases,150 draw/question-chain rehearsals and450 reveal cases. The revised finale was reenacted by the same three selected agents and host. The revised full14-page kit has not undergone a second independent full-cohort playthrough. Live conversation, measured speech timing, actual printing/cutting, music/lighting, physical ballot handling, animal retention and discovery searching remain untested. A small real-player rehearsal is the appropriate next evidence for those questions.

Original stage notes, ballots, detailed feedback, selected speakers and ending assessments are preserved in sibling player directories. The final agent’s initial turn hit a usage limit after saving its files; it later resumed to complete the ending. Synthetic animal mappings in adjudicator.json are TEST DATA ONLY and must never be used as a guest check-in list.
