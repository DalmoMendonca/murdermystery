# Belle Tament / Junior Curator

Honorary character for Bennet, Tiffany's daughter. Separate from the adult mystery: no animal, private clues, timed turns or counted accusations.

Print the ten-page activity book single-sided at 100%, with crayons or colored pencils. Tiffany's one-page notes contain costume suggestions and puzzle answers. Both PDFs are in OPEN_FREELY and have direct site downloads.

Editable copy: source/children/belle_tament.yaml. Image-generated artwork and saved prompts: assets/children/belle/. Reproducible page layout: scripts/belle_activity.py. The pinned kit build includes these automatically. Standalone regeneration: python scripts/belle_activity.py.

All 14 pages were rendered and visually reviewed. Four short search words each have exactly one forward-across/down match. The two galleries have five large object changes (small painterly variations are not puzzle targets). All 75 existing game PDFs and 184 previously sent public files remain unchanged.
